# Tag

A user-defined label with a color, used to categorize tasks.

## Fields
| Field   | Type       | Description          |
|---------|------------|----------------------|
| `id`    | `TagId`    | Unique identifier    |
| `owner` | `UserId`   | The owner of the tag |
| `label` | `String`   | The label of the tag |
| `color` | `TagColor` | The color of the tag |

## Enums

### TagColor
`RED` `ORANGE` `YELLOW` `GREEN` `TEAL` `BLUE` `PURPLE` `PINK` `GRAY`
