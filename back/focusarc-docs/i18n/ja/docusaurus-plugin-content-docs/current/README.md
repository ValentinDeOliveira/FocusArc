# Focus Arcはなんですか？

Focus Arcはプロダクティビティプラットホームです。
ユーザーにタスクと集中セッションを管理できますし。

アークというのは期限付き目標を数週間から数ヶ月にわたります。
格アークはチャプターを含みました。チャプターといのうのは、その目標の中で、
論理的な分とか話題です。格チャプターはタスクを含みました。タスクというのは、ユーザーが日々の具体的な作業単位を計画して、
果たしています。

## 主な特徴

- **タスク管理**：タスクを作りたり、計画したり、管理したります
- **集中セッション**：どのタスクにもセッションを始められます。推定時間は終わると、タイマーは
「**オーバータイムのモード**」に入って、中断なし、入力不要。実際の時間（オーバータイム付属）は
停止時に記録されます。
- **時間管理**：どのように時間の使い方を日々とアークのレベルか確認します
- **分析**：プロダクティビティを可視化したり、時間に伴う推定精度したりします

## 技術スタック

- **バックエンド**：　Java 17、Spring Boot 4.0.2、MongoDB 6.0
- **フロントエンド**：　Angular 21、TypeScript、Tailwind CSS
- **デプロイ**： Docker、Github Actions
- **その他**： Docusaurus、JaCoCo、Lombok
