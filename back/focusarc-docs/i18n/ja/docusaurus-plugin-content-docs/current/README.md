# Focus Arcとは何ですか？

Focus Arcはプロダクティビティプラットフォームです。
ユーザーがタスクと集中セッションを管理できるようにします。

アークというのは、数週間から数ヶ月にわたる期限付き目標です。
各アークはチャプターを含みます。チャプターというのは、その目標の中の論理的なセグメントや話題です。
各チャプターはタスクを含みます。タスクというのは、ユーザーが日々計画して実行する具体的な作業単位です。

## 主な特徴

- **タスク管理**：タスクを作ったり、計画したり、管理したりできます
- **集中セッション**：どのタスクにもセッションを始められます。推定時間が終わると、タイマーは自動的に
「**オーバータイムモード**」に入って、中断なし、入力も不要です。実際の時間（オーバータイムを含む）は
停止時に記録されます。
- **時間管理**：日々とアークレベルの両方で、時間の使い方を確認できます。
- **分析**：プロダクティビティと経時的な推定精度を可視化できます。

## 技術スタック

- **バックエンド**：　Java 17、Spring Boot 4.0.2、MongoDB 6.0
- **フロントエンド**：　Angular 21、TypeScript、Tailwind CSS
- **デプロイ**： Docker、Github Actions
- **その他**： Docusaurus、JaCoCo、Lombok
